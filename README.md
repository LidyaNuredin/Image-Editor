# 🎨 Python Image Editor

A modern, dark-themed desktop image editor built with **Python**, **CustomTkinter**, and **Pillow (PIL)**. It features real-time image manipulation, filters, drawing tools, and text overlays.

## ✨ Features
* **Position Controls:** Rotate, zoom, and flip/mirror images easily.
* **Color Adjustments:** Grayscale conversion, inversion, brightness, and vibrance sliders.
* **Effects & Filters:** Gaussian blur, unsharp mask contrast, emboss, contour, find edges, and edge enhance.
* **Text & Paint Overlays:** Add custom text with font scaling and RGB color pickers, or draw directly onto the image with a custom brush tool.
* **Export Options:** Save edited images quickly as JPG or PNG.
